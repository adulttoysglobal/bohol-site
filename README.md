# BOHOL 品牌官网

Astro 静态官网 + Decap CMS（基于 Git 的 Headless CMS）。使用授权目录内的真实产品白底图，源资料与报价单没有修改，报价单没有复制到网站。

## 官网内容

当前共 29 个页面（含 404），兼顾消费者与经销商：10 款产品详情、分类及搜索、品牌介绍、技术设计、6 篇产品知识、产品对比指南、可打印目录、商务合作、联系入口、服务支持及型号文档说明。

商务表单可选产品、下载或复制询盘文本，所有内容在浏览器本地生成，不自动发送。填写网站设置里的真实邮箱后会显示邮件草稿入口；填写 WhatsApp 后联系页会显示相应链接。暂未提供这两项联系方式。

后台增加文章集合，可添加和编辑 Markdown 文章、摘要、配图和分类。公司全称依据资料更新为“东莞美洲豹科技有限公司”；BOHOL 仍是可替换的暂用品牌展示名。

## 本机使用

双击 `启动网站.cmd`，然后访问：

- 官网：http://127.0.0.1:4321/
- 中文内容后台：http://127.0.0.1:4321/admin/

后台“产品”可编辑、添加产品、上传图片和填写 SEO 字段；“网站设置”可修改品牌、首页简介、全站描述和询盘邮箱。保存至本地后，开发预览会更新。产品参数使用提供的图片资料，不包含认证、销量或疗效承诺。

## 发布状态

托管版本是只读静态站点。私有预览仅用于所有者审核，不会被搜索引擎收录。公开上线须确认正式品牌、域名、访问范围和联系方式。

Decap 本地编辑服务可用。远程编辑需要另行配置 GitHub/GitLab 等内容仓库与 OAuth/Git Gateway，并连接构建发布流程；当前不声称具备远程编辑或自动发布。编辑本地内容后，需要重新构建和部署才能更新已托管的版本。

## 开发

```sh
npm install
npm run dev
npm run cms
npm run build
```

CMS 仅绑定 127.0.0.1，允许来源为 http://127.0.0.1:4321。后台前端文件自托管，不会在访客页面加载。`src/data/products/*.json` 为产品内容；`src/data/settings.json` 为站点配置；`src/content.config.ts` 校验字段。

## 上线配置

在 `astro.config.mjs` 更新正式 site 地址，同时更新 `public/robots.txt` 的 sitemap URL。标题、描述、canonical、Product/Breadcrumb JSON-LD、站点地图已实现。未添加虚假价格、评分或库存。图片、字体均本地托管。

当前未设置在线支付、询盘接收服务、用户账户或聊天功能。填写真实询盘邮箱后，产品详情会显示邮件联系入口。
